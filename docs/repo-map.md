# Repository Map

CVocab is split across six private repositories. Each repo owns a clear part of the product or delivery workflow.

| Repository             | Type    | Main responsibility                        |
| ---------------------- | ------- | ------------------------------------------ |
| `Flutter cv-app`       | Flutter | iOS/Android product app                    |
| `NestJS cv-api`        | NestJS  | Backend APIs, persistence, queues, workers |
| `NextJS cv-web`        | Next.js | Public and authenticated web app           |
| `NextJS cv-bo`         | Next.js | Backoffice/admin app                       |
| `Python cv-data`       | Python  | Internal data-processing automation        |
| `Load test cv-be-test` | k6      | Backend performance and smoke testing      |

## Boundary

Only repository labels are shown here. Private remote URLs, commit hashes, branch names, deployment hosts, and internal paths stay out of the public case study.
